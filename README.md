# MTDM AI Lab

**Multi-Tech Digital Manufacturing & AI Laboratory**

A free, browser-based workspace for exploring selected engineering and emerging-technology concepts.

- **Live workspace:** https://aiagent16051987.github.io/MTDM-AI-Lab/
- **Source code:** https://github.com/aiagent16051987/MTDM-AI-Lab

## Available workspaces

- **Electronics:** selected circuit simulation and guided experiments.
- **IoT:** local sample telemetry and optional MQTT demonstration.
- **AI:** a small browser-based classifier demonstration.
- **Robotics:** basic 2D mobile-robot kinematics and path planning.
- **Quantum:** introductory single- and two-qubit state and gate demonstrations.
- **Nano:** a simplified 2D molecular-interaction model.
- **Additive manufacturing:** process overviews, 3D previews and approximate planning estimates.

These are limited educational and exploratory tools. They are not substitutes for professional engineering software, laboratory measurements, validated scientific models, machine-specific planning tools or qualified review. Results depend on the assumptions and inputs of each workspace.

## Run locally

Requirements: Node.js and npm.

```bash
git clone https://github.com/aiagent16051987/MTDM-AI-Lab.git
cd MTDM-AI-Lab
npm install
npm run dev
```

To run the available checks and create a production build:

```bash
npm test
npm run build
```

## Use and safety

The site is delivered as a static website. Browser features may use public third-party libraries or services. Do not enter secrets, personal information or confidential material into public services or demonstrations.

Use outputs for learning and preliminary exploration only. Do not use them alone to make safety-critical, medical, biological, industrial or other high-consequence decisions, or to control physical equipment.
